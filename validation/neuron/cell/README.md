# Cerebellar whole-cell comparisons

Each model pairs a NEURON template with a BrainCell template and shared parameters.
The regular notebooks call one runner to apply a soma current clamp and record soma
voltage. Analysis and plotting can be repeated from saved traces without simulation.

## Models and templates

- [BC MA2025](bc_ma2025/run.ipynb): basket cell; [model notes](bc_ma2025/bc.md).
- [DCN SU2015](dcn_su2015/run.ipynb): native HOC geometry; [model notes](dcn_su2015/dcn.md).
- [GoC MA2020](goc_ma2020/run.ipynb): Golgi cell; [model notes](goc_ma2020/goc.md).
- [GrC MA2020](grc_ma2020/run.ipynb): imported morphology; [full variant](grc_ma2020/run_full.ipynb) adds axonal sections.
- [IO ZH2019](io_zh2019/run.ipynb): soma model; [model notes](io_zh2019/io.md).
- [PC MA2024](pc_ma2024/run.ipynb): soma and dendrite geometry; [model notes](pc_ma2024/pc.md).
- [SC MA2021](sc_ma2021/run.ipynb): stellate cell; [model notes](sc_ma2021/sc.md).

Each model's `*_neuron.py` and `*_braincell.py` own morphology construction,
regional mechanisms and discretization. `parameters.py` loads shared model parameters;
GrC full has its own pair of templates and parameter loader. Source morphologies,
MOD files and parameter tables live in [data/cerebellum](../../../data/cerebellum/README.md).
DCN's HOC parsing helpers remain in its `native/` directory.

## Run a comparison

Use a repository checkout with BrainCell installed and the
[NEURON dependencies](../README.md). From the repository root:

```bash
python -m validation.neuron.cell.run --cell pc_ma2024
python -m validation.neuron.cell.run --cell grc_ma2020_full --dt-ms 0.05 --duration-ms 10
```

The runner starts a fresh worker process for each comparison and reuses the shared
[MOD compiler](../_mechanisms.py). Compilation requires `nrnivmodl` and a C++ compiler;
unchanged sources reuse their compiled library. The worker uses the same Python
environment as the caller. Separate processes isolate NEURON mechanisms and global settings.

Python and notebooks use the same entry point:

```python
from dataclasses import replace
from validation.neuron.cell.protocol import get_model
from validation.neuron.cell.run import run_case

protocol = get_model("pc_ma2024").default_protocol
protocol = replace(protocol, dt_ms=0.05, duration_ms=10.0)
result = run_case("pc_ma2024", protocol=protocol)
print(result.output_dir)
```

[Protocol](protocol.py) contains `dt_ms`, `duration_ms`, `delay_ms`, `stim_dur_ms`,
`amp_nA`, `temperature_celsius`, `v_init_mV` and `precision`. CLI overrides use
hyphenated lowercase names, such as `--amp-na` and `--precision`.
The duration must be an integer multiple of the positive time step.

Defaults reproduce the original eight notebooks, including float32 for GoC and PC
and float64 for the others. Use `precision=64` or `--precision 64` for a separate
double-precision experiment. Both simulators receive the same protocol; BrainCell
uses `staggered`, NEURON uses fixed-step integration. Recording and stimulation
are at `soma(0.5)`.

Each call creates `<model>/artifacts/<model>-<run-id>/`. `output_dir=` or
`--output-dir` changes the parent directory. The returned [ComparisonResult](results.py)
contains `neuron` and `braincell` traces, each with one-dimensional `time_ms` and
`voltage_mV` arrays, plus run metadata and the output directory.

- `request.json` and `run.log`: requested protocol and worker diagnostics.
- `traces.npz` and `metadata.json`: original sample arrays, actual protocol, model,
  recording semantics, software versions and finite-voltage flags.
- `metrics.json`, `aligned.npz` and `comparison.png`: derived analysis and figure,
  generated by the CLI or explicitly by notebook calls.

Worker failures report the log location. Nonfinite voltages remain in the raw
result for diagnosis; accuracy analysis rejects them.

## Analyze and redraw

```python
from validation.neuron.cell.results import load_result
from validation.neuron.cell.analysis import analyze, save_analysis
from validation.neuron.cell.plotting import plot_analysis, save_plot

result = load_result(run_directory)  # An existing run's output_dir.
analysis = analyze(result, threshold_mV=0.0)
save_analysis(analysis, result.output_dir)
figure, axes = plot_analysis(analysis)
axes[0].set_title("PC soma response")
save_plot(figure, result.output_dir / "comparison.pdf")
```

For an existing result, the CLI also works in an environment with NumPy and
Matplotlib and no simulator installation:

```bash
python -m validation.neuron.cell.run --load /path/to/saved/run --threshold-mv 0
```

Analysis matches recorded sample times with an absolute roundoff tolerance of
`1e-8 ms`. NEURON includes `t=0`; BrainCell StateProbe records after each step,
starting at `dt`. Only the extra NEURON initial point is removed. A different time
grid raises an error; voltage samples are neither interpolated nor silently truncated.

Voltage metrics are RMSE, MAE and maximum absolute error. The signed difference is
BrainCell minus NEURON. Spike detection uses upward threshold crossings and linear
interpolation between adjacent samples in the common recorded window. Equal counts
are paired in temporal order; unequal counts retain separate event lists. Metrics
quantify differences; model-specific accuracy acceptance requires an explicit tolerance.

The figure shows both voltage traces, spike markers and the error curve. Plotting
returns Matplotlib objects and performs no simulation. Derived files can be refreshed;
raw saved results are protected against accidental overwrite.

## Maintenance and verification

[run.py](run.py) coordinates execution; [protocol.py](protocol.py) registers models
and experiment defaults. [results.py](results.py), [analysis.py](analysis.py) and
[plotting.py](plotting.py) own storage, numerical comparison and figures respectively.
New regular models supply a pair of builders and a ModelSpec registration.

```bash
pytest -q validation/neuron/cell/protocol_test.py validation/neuron/cell/results_test.py \
  validation/neuron/cell/analysis_test.py validation/neuron/cell/plotting_test.py \
  validation/neuron/cell/run_test.py
pytest -q validation/neuron/cell/pc_ma2024
```

Run model-specific NEURON tests in a separate process per model. The
[profiling workflow](../../../benchmarks/profiling/README.md) still imports the
same BrainCell builders; its timing protocols are maintained independently.
[Import progress](../cerebellum-import-progress.md) tracks model accuracy work.
Each model's `history/` retains its earlier comparison notebooks and saved outputs.

studies to this shared workflow, then consolidate their duplicate model construction.
