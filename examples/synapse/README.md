# Synapse examples

[Synapse placement](synapse.ipynb) demonstrates point placement, SynapseView access,
parameter broadcasting and sampling along morphology regions. Its ASC example
reads the shared GoC morphology from `data/cerebellum/`; the 3D plot uses Plotly.

Continue with [Connection](../network/connection.ipynb) to deliver events and
[Network](../network/network.ipynb) to run populations together.
Interface details live in [Synapse Design](../../docs/design/synapse/TODO.md).
